# 1. Deliver the factory as reusable GitHub Actions, not a GitHub App

The factory runs inside each client repo's GitHub Actions, called from this repo, rather than as a hosted orchestrator behind a GitHub App (as aint-farm does). This removes the App, the server and the per-installation credential store, so an organisation like Skylight can adopt it without trusting a third-party App or a server it doesn't run. In exchange, the factory is tied to GitHub Issues and Actions and accepts their limits (event triggers, token rules, runner time limits) in place of an orchestrator's freedom. aint-farm carries on alongside it as a personal hub. This rules out any GitHub App, including one each client registers for itself; the factory acts with a token the client provides (ADR 0003).
